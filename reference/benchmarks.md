# Benchmarks

Rough industry reference points the diagnostician uses as **sanity checks** — to judge whether a number is "normal drift" or "the story." These are ballpark ranges for small trades operators, not precise figures; treat them as smell tests, not truth. When a real figure for the specific business is available, always prefer it.

---

## Target gross margins (direct-cost basis)

| Trade | Typical gross margin on labor+materials |
|---|---|
| Roofing | 25–40% |
| Plumbing (service) | 40–55% |
| Plumbing (new construction) | 20–30% |
| HVAC (install) | 25–40% |
| HVAC (service) | 40–60% |
| Electrical | 30–45% |
| Remodeling / GC | 15–30% |
| Landscaping | 25–45% |

If a job's *target* margin was set well below its trade's normal band, the "loss" may have been baked into the bid — a pricing failure, not a job failure.

## Labor burden multiplier

- Typical range: **1.25×–1.6×** of base wage.
- Roofing/framing skew high because workers' comp rates are steep.
- A rule that ignores burden (multiplier ≈ 1.0×) is itself a finding.

## Materials waste allowance

| Material | Typical waste allowance |
|---|---|
| Roofing shingles | 10–15% |
| Drywall | 10% |
| Framing lumber | 5–10% |
| Pipe / fittings | 5–10% |
| Wire | 5–10% |
| Tile | 10–15% |

A materials overrun *within* the waste band is usually noise. Beyond it, look for added quantity (scope) or stale pricing.

## Change-order frequency

On remodels and anything touching existing structures, expect *some* change orders — homeowners add things. A remodel that ran with **zero** written change orders but overran on labor+materials proportionally is a red flag for unbilled scope creep (failure mode C1).

## Retainage

- Common hold: **5–10%** of contract on larger/commercial jobs.
- If revenue is short by almost exactly the retainage percentage, suspect an uncollected final draw (C3) before anything else.

## Normal-drift threshold

As a working rule: a single bucket within **±5–8%** of estimate is usually normal execution drift, not a cause. Look past it to the bucket that's meaningfully outside the band. Don't build a diagnosis on noise.
